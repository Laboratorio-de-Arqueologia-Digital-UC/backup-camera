# User Code of Conduct

## 1. Respect

Treat everyone with respect. We are a community of professionals and enthusiasts. Harassment, hate speech, and discrimination will not be tolerated.

## 2. Collaboration

Work together and help each other. Constructive criticism is welcome, but personal attacks are not.

## 3. Integrity

Do not post malicious code or attempt to compromise the security of the project or its users.

## Enforcement

Violations of this code of conduct may result in a ban from the repository and community channels.
